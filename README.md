# Healthcare Data Analysis Project

## Project Overview

The Healthcare Data Analysis Dashboard project focuses on analyzing hospital and patient records to identify trends related to patient admissions, billing amount, medical conditions, and insurance providers.

The project helps healthcare organizations understand patient data better through data analysis and interactive dashboard visualization.

---

## Objective
- Analyze healthcare patient records
- Track hospital billing information
- Identify common medical conditions
- Monitor insurance provider usage
- Build an interactive Power BI dashboard for decision-making

---

## Dataset Information
The dataset contains healthcare patient records with details such as:

- Patient Name
- Age
- Gender
- Blood Type
- Medical Condition
- Date of Admission
- Doctor Name
- Hospital Name
- Insurance Provider
- Billing Amount
- Admission Type
- Medication
- Test Results

Total Records: **55,500+**

## Key Insights

- Average patient age is around 51 years
- Billing amount average is approximately ₹25,539
- Common conditions include Arthritis, Diabetes, Hypertension, Obesity, and Cancer
- Insurance provider data helps track patient coverage trends
- Dashboard makes hospital reporting faster and easier
